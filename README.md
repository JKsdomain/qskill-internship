# Q-Skill Internship

Repository containing completed tasks for the Q-Skill Internship program.

## Project Overview

- **Task 1: Data Cleaning & Preprocessing (`task1/`)**
  - Notebook: `TASK-1.ipynb`
  - Focus: Data cleaning, handling missing values, duplicate removal, standardization, and EDA.

- **Task 2: Student Performance Analysis and Prediction (`task2/`)**
  - Notebook: `Student_Performance_Analysis_and_Prediction (3).ipynb`
  - Focus: Exploratory data analysis, feature engineering, and predictive modeling for student performance.

- **Task 3: Customer Segmentation Using Data Analysis & Clustering (`task3/`)**
  - Notebook: `task3.ipynb`
  - Focus: Unsupervised machine learning, customer segmentation, clustering, and profiling.

- **Task 4: House Price Prediction (`task4/`)**
  - Notebook: `task_4.ipynb`
  - Focus: Regression modeling, model evaluation, and error analysis for house price prediction.
